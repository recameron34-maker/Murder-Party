**8:30** — Clara meets Arthur.

**8:45** — Molly visits the study. Raven is on desk.

**8:50** — Jimmy confronts Arthur about the will.

**9:20** — Kevin and Arthur argue. Kevin goes outside.

**9:29** — Arthur texts Morgan: "My study. 9:35. We settle this tonight."

**9:31** — Annie delivers Arthur's drink. Arthur is alive and alone.

**9:32** — Annie passes Morgan heading toward Arthur's study.

**9:34** — Morgan enters.

**9:36–9:37** — Maya overhears Arthur arguing with a woman about missing money.

**~9:38** — Morgan kills Arthur with the bronze raven.

**9:40–9:41** — Jimmy and Alma see Morgan around the library.

**9:45** — THE LIGHTS GO OUT.

Important:

**Arthur is already dead.**

The blackout is unrelated to the murder.

You, Reggie, later discover that an old electrical circuit tripped during preparations for the Midnight Supper.

This is deliberately mundane.

The killer did not plan the blackout.

Everyone merely assumed the murder happened during it.
